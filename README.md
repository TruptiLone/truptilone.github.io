## About this site

A single static page served by **GitHub Pages** from the `main` branch. `index.html` contains the whole site (inline CSS, no build step), with `og.png` and `favicon.svg` for link previews.

Each project card has an `id` (e.g. `id="cafepilot"`); keep it when editing a card, or old links break. New card: add an `id` and a `card-anchor` link like the others.

To update: edit `index.html` and commit to `main` — the live site refreshes within a minute or two.
